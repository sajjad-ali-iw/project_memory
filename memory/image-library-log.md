## Gotchas

- **Redacting text (e.g. a real person's name) inside a user-supplied screenshot:** don't just crop it out if the surrounding content still matters — patch it in place with PHP+GD. Recipe used successfully for the /odoo-ai-agents/ hero: (1) sample pixel colors in a small grid across the target region to find the exact background fill color and the text color (`imagecolorat` + `imagecolorsforindex`), since UI elements are rarely pure flat colors; (2) scan single rows/columns for color-delta jumps to find the precise pixel bounding box of the element (a badge/pill in this case) rather than eyeballing coordinates from a downscaled preview; (3) redraw the full element shape (e.g. a stadium/pill = filled rect + two `imagefilledellipse` end caps) in the sampled background color to fully cover the old text, not just a plain rectangle patch; (4) render the replacement text with `imagettftext` using a system font (`C:\Windows\Fonts\arialbd.ttf` on this Windows box) in the sampled text color, centered via `imagettfbbox` width/height math. Always render a preview and send it for approval before converting/deploying — the user rejected a first pass that cropped tightly to just the modal (wanted the dimmed background app chrome kept, "so it looks like the enterprise environment where this connector renders").
- Pexels photo 6803525 was almost picked for two different pages in the same session before being caught — always check this log first.
- Very-low Pexels photo IDs (e.g. 7374) use an older URL scheme — `pexels-photo-<id>.jpeg` 404s as "Source image is unreachable"; fetch the photo page and read the real filename slug (e.g. `startup-photos.jpg`) from its og:image/src instead.
- `pexels.com` is blocked by policy in the Browser pane (`navigate` fails outright) — approval previews use plain markdown links in chat instead, see [[image-approval-preview-method]].
- Always view a candidate photo directly (download + `Read`, or the Artifact grid) before proposing it from a text description alone — a Pexels search description called a photo a "workflow strategy discussion" when the actual on-screen content was a "Workflow Wars" gamified-training mockup, and another called a stock-trading candlestick terminal a fit for "Data, BI & AI." Both looked right in text and wrong in the image (2026-08-07, /erp-integration/ tabs 4-5).
